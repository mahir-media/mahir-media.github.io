# Mahir Media site
Static site: HTML, CSS, JavaScript, GSAP, Three.js. No build step.

- **Add a project:** in `index.html`, copy one `<article class="panel">` inside `#work` and edit it.
- **Add a real testimonial:** add a section after `#work` only once you have a permissioned quote.
- **Colours:** change the variables at the top of `style.css` (`--em` is the ember accent).
- **Music:** put your licensed loop at `assets/audio/piano.mp3`.
- **Form:** enquiries go to a Google Sheet through Apps Script; see `form_to_sheet.gs`.
